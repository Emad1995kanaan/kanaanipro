# KANANI TV (Android TV)

مشغّل أندرويد TV: دخول باسم مستخدم وكلمة مرور، والهوست مخفي (بيجي من دومين الإعدادات تبعك).

## الملفات (app/src/main/java/com/kanani/tv)
- `Theme.kt`: ألوان اللوجو و`FocusBox` (تأثير التركيز بالريموت).
- `Config.kt`: بيجيب عنوان السيرفر من `https://cfg.kanani.com/config.json` ويخزّن آخر نسخة.
- `Api.kt`: واجهة Xtream، روابط التشغيل، وتسجيل الدخول المحفوظ.
- `MainActivity.kt`: الدخول، الرئيسية (صفين بوسترات + شريط أقسام دائري سفلي)، الأقسام الكاملة، الإعدادات، المسلسلات والحلقات، والمشغّل.

## الرئيسية
- صف "أحدث الأفلام" وصف "أحدث المسلسلات" (بالأحدث إضافة) مع نجوم التقييم.
- شريط سفلي بالنص: القنوات، أفلام، مسلسلات، إعدادات + تاريخ انتهاء الاشتراك.

## البث المباشر (القنوات)
- أول ما تدخل: الفيديو بملء الشاشة وفوقه قائمة زجاجية: تصنيفات مرقّمة (01 الكل، 02 المفضلة، 03 ...) وقنوات مرقّمة (001، 002 ...).
- OK على قناة = تشغيل وإخفاء القائمة.
- وانت بتشاهد: السهم فوق = القناة التالية، السهم تحت = السابقة، OK أو يمين/يسار = فتح القائمة، Back = إخفاء القائمة ثم رجوع.
- ضغطة مطوّلة على OK فوق قناة = إضافة/إزالة من المفضلة. وبيتذكّر آخر قناة.

## الأقسام (أفلام، مسلسلات)
- كل قسم شاشة لحاله: التصنيفات بالجنب (لوحة زجاجية، أولها "الكل" ثم بنفس ترتيب السيرفر) والمحتوى (بوسترات) باليمين.
- فوق عالشمال خانة بحث: بتكتب وبيفلتر فوراً المحتوى اللي بالتصنيف المفتوح.
- التنقل فوق/تحت بين التصنيفات بيعرض محتوى كل تصنيف فوراً، والضغط OK على تصنيف بينقلك لأول بوستر فيه.
- Back بيرجع للرئيسية.

## التنقل بالريموت
- يمين/يسار: بين البوسترات أو بين الأقسام (الأقسام بتتبدل بمجرد التنقل بدون ضغط).
- فوق/تحت: بين الصفوف (التصنيفات) وشريط الأقسام.
- OK: تشغيل (قناة/فيلم) أو فتح المسلسل. Back: رجوع خطوة.
- أول ما تفتح الرئيسية التركيز بيروح لأول بوستر، وتسجيل الدخول بيتحفظ (دخول تلقائي).

## الألوان (من اللوجو)
أزرق `#2F6BFF`، أزرق مضيء `#6C9BFF` (إطار التركيز)، فضي `#E3E7EE`، كحلي `#0B1B4D`، خلفية `#070B14`.

## قبل التشغيل
1. افتح المجلد في Android Studio.
2. الهوست الأساسي موجود (مشفّر Base64) في `Config.kt`؛ `CONFIG_URL` اختياري للإعدادات عن بعد.
3. ارفع `config.json` على دومينك:
   { "host": "https://api.kanani.com", "app_name": "KANANI" }
4. اللوجو والأيقونة والبانر جاهزين في `res/drawable`.

## ملاحظات
- الهوست الحالي `http` (بدون تشفير)، فمفعّل cleartext بالـ Manifest. الأفضل لاحقاً HTTPS.
- الهوست مخفي عن المستخدم العادي، بس مش 100%؛ استخدم وسيط + توكن مؤقت للبث.
- المحتوى لازم يكون إنتاجك أو مرخّص لك.

## المظهر (من الإعدادات)
- 5 ثيمات ألوان: أزرق، بنفسجي، زمردي، غروب، وردي.
- 3 أشكال للرئيسية: كلاسيكي، سينمائي، بطاقات.
- حجم العرض (زوم أوت) للمباشر والأفلام والمسلسلات: 100/90/85/80/70% (الافتراضي 85%).
- أيقونات عصرية مرسومة بالكود (Look.kt).
